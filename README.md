# ポケモン図鑑クイズ

図鑑の解説文だけを見た出題者がイラストを描き、ほかの人がその絵から元のポケモンを当てる、
お絵描き伝言型のパーティゲームです。iPad 1台をみんなで囲んで遊ぶことを想定しています。

**ファンによる非公式・非営利の制作物です。**

---

## 遊びかた

1. 出題者ひとりが、ポケモンの**図鑑解説文だけ**を見ます（名前と図鑑 No. は伏せられています）
2. 出題者はその文章をヒントに、そのポケモンの絵を描きます
3. ほかの人は絵を見て、どのポケモンかを当てます
4. 全員が1回ずつ出題者を担当したら結果発表です

### モード

| モード | 内容 |
|---|---|
| 対戦モード | 解答者はひとりずつ順番に答える。**解答力**（自分が当てた数）と**伝達力**（自分の絵で当ててもらえた人数）の合計でランキング |
| 協力モード | みんなで相談して答えをひとつ出す。チームで何問正解できるかに挑戦 |

### 出題範囲

- **ポケモンマスターモード** … 全国図鑑 No.1〜898（全898種）
- **あの頃のポケモンモード** … ゲームタイトルを選ぶと、その時点までに登場した全ポケモンから出題（累積方式）

> 日本語の図鑑解説文は **No.1〜898（ソード・シールドまで）** にのみ存在するため、出題はこの範囲です。

### 遠隔参加

プレイヤー登録で「リモート」を ON にすると、その人の解答画面に「（代理入力）」と表示されます。
ビデオ通話で画面共有し、口頭の解答をホストが代理入力してください。

## 開発・動作確認

### ローカルで動かす

```sh
cd pokemon_quiz
python3 -m http.server 8000
# → http://localhost:8000 を Safari / Chrome で開く
```

`index.html` をダブルクリックしても動きます（ES modules を使っていないため `file://` でも動作します）。

### iPad 実機で確認する（本番と同じ条件）

```sh
ipconfig getifaddr en0     # MacBook の IP を確認
# → iPad の Safari で http://<そのIP>:8000 を開く
```

確認すること:

- Apple Pencil と指の両方で線が引けるか、筆圧で太さが変わるか
- キャンバスを触ったときにページがスクロール／引っぱり更新されないか
- 日本語キーボードで解答入力ができるか（変換確定で誤送信しないか）
- 横向き・縦向きの両方でレイアウトが崩れないか

### デバッグ用パラメータ

`?debug=1` を付けると:

- 画面上部に S1〜S5 の移動ボタンが出る
- タイマーが 5 秒に短縮される
- 出題ポケモンが固定される（ピカチュウ → ヒトカゲ → フシギダネ …）
- 解答判定の自己テストがコンソールに出る

## ファイル構成

```
pokemon_quiz/
├── index.html          # 5画面すべてを含む本体
├── css/
│   ├── dex.css         # 図鑑筐体デザイン（共通パーツ）
│   └── screens.css     # 各画面固有のレイアウト
├── js/
│   ├── state.js        # 状態オブジェクト + sessionStorage 復帰
│   ├── dexdata.js      # 世代別ID範囲テーブル・抽選・伏字処理
│   ├── pokeapi.js      # PokeAPI 取得 + localStorage キャッシュ + プリフェッチ
│   ├── judge.js        # 解答の正規化・あいまい一致判定
│   ├── canvas.js       # お絵描き（Pointer Events / undo / 消しゴム）
│   ├── sfx.js          # Web Audio 効果音（音声ファイルなし）
│   └── app.js          # 画面遷移・各画面のイベント配線（最後に読み込む）
├── tools/
│   └── build_offline.py  # 898種を取得 → JSON化 → 1枚HTMLを出力
├── robots.txt          # noindex
├── .nojekyll           # GitHub Pages 用
└── .gitignore          # cache/ dist-offline/ を除外
```

フレームワーク・ビルドツールは一切使っていません（バニラ HTML/CSS/JS）。
`js/*.js` はクラシックな `<script>` タグでこの順に読み込みます（`app.js` が最後）。

## オフライン版（当日の保険）

会場のネット環境が不安な場合に備え、**HTML 1枚に全データを埋め込んだオフライン版**を生成できます。

```sh
python3 tools/build_offline.py                # 文字のみ版（軽量・推奨）
python3 tools/build_offline.py --with-sprites # ドット絵入り版（約6MB）
```

出力: `dist-offline/pokemon-quiz-offline.html`
このファイルを iPad の「ファイル」アプリに入れれば、**機内モードのまま**遊べます。

### PokeAPI Fair Use への配慮

このスクリプトは合計 919 リクエスト（`/pokemon-species/1〜898/` と `/type/1〜21/`）を発行します。
PokeAPI は無料・認証不要ですが Fair Use ポリシーがあるため、以下を実装しています。

- 同時接続は最大 3、リクエスト間に 150ms のウェイト（全体で約4〜5分）
- `cache/` にディスク保存し、2回目以降は再取得しない（中断しても続きから再開できる）
- User-Agent を明示（`pokemon-dex-quiz/1.0 (personal fan project)`）
- 失敗時は指数バックオフで最大3回リトライ、失敗が多ければ中断して報告
- 進捗を `123/919` の形で表示

ブラウザ版も同様に、取得結果を `localStorage` にキャッシュして再取得を避けています。

### リポジトリに図鑑データを含めない方針

`cache/` と `dist-offline/` は `.gitignore` で除外しています。
**図鑑テキスト・画像はリポジトリに一切入りません。** 実行時にブラウザが PokeAPI から直接取得します。
