# ポケモン図鑑クイズ

図鑑の解説文だけを見た出題者がイラストを描き、ほかの人がその絵から元のポケモンを当てる、
お絵描き伝言型のパーティゲームです。iPad 1台をみんなで囲んで遊ぶことを想定しています。

**ファンによる非公式・非営利の制作物です。**

---

## 遊びかた

1. 出題者ひとりが、ポケモンの**図鑑解説文だけ**を見ます（名前と図鑑 No. は伏せられています）
2. 出題者はその文章をヒントに、そのポケモンの絵を描きます
3. ほかの人は絵を見て、どのポケモンかを当てます
4. 全員が1回ずつ出題者を担当したら結果発表です

### モード

| モード | 内容 |
|---|---|
| 対戦モード | 解答者はひとりずつ順番に答える。**解答力**（自分が当てた数）と**伝達力**（自分の絵で当ててもらえた人数）の合計でランキング |
| 協力モード | みんなで相談して答えをひとつ出す。チームで何問正解できるかに挑戦 |

### 出題範囲

出題範囲は 2 つの軸で決めます。どちらも複数えらべます。

**① 出題するポケモン（世代）**
第1〜第9世代から選びます。**その世代で新しく登場したポケモンだけ**が出ます（累積ではありません）。
たとえば第2世代だけを選べば No.152〜251 の 100 種、第1＋第9世代なら 271 種になります。

**② 図鑑説明の出典ソフト**
お題に使う図鑑説明を、どのソフトのものにするか選びます。「おまかせ」なら全ソフトから。

| 出典 | 使える種数 | | 出典 | 使える種数 |
|---|---|---|---|---|
| 赤・緑・青・ピカチュウ | 151 | | ウルトラサン・ウルトラムーン | 403 |
| 金・銀・クリスタル | 251 | | Let's Go! ピカチュウ・イーブイ | 153 |
| ルビー・サファイア・エメラルド | 385 | | ソード・シールド | 609 |
| ファイアレッド・リーフグリーン | 384 | | LEGENDS アルセウス | 226 |
| ダイヤモンド・パール・プラチナ | 491 | | スカーレット・バイオレット | 664 |
| ハートゴールド・ソウルシルバー | 256 | | X・Y | 721 |
| ブラック・ホワイト（BW2 含む） | 303 | | オメガルビー・アルファサファイア | 721 |
| サン・ムーン | 302 | | | |

該当するポケモンが 0 種になる組み合わせ（例：第2世代 × 赤・緑）はボタンが選べなくなり、
選べる種数がその場で表示されます。

### 同じポケモンが続けて出ないようにする

出題した図鑑 No. を、その端末の `localStorage` に古い順で記録しています。
抽選では **まだ出していないポケモンを優先**し、足りなくなったら古く出したものから戻します。
記録しているのは「何が出たか」だけで、プレイヤー名や得点は残りません。

出題範囲の下に「この端末での出題ずみ：N / M 種」と出ます。
［履歴をリセット］でいつでも消せます。

### 遠隔参加

プレイヤー登録で「リモート」を ON にすると、その人の解答画面に「（代理入力）」と表示されます。
ビデオ通話で画面共有し、口頭の解答をホストが代理入力してください。

## 開発・動作確認

### ローカルで動かす

```sh
cd pokemon_quiz
python3 -m http.server 8000
# → http://localhost:8000 を Safari / Chrome で開く
```

`index.html` のダブルクリックでは動きません。図鑑データを `fetch` で取りにいくため、
必ず上のようにローカルサーバー経由で開いてください。

### iPad 実機で確認する（本番と同じ条件）

```sh
ipconfig getifaddr en0     # MacBook の IP を確認
# → iPad の Safari で http://<そのIP>:8000 を開く
```

確認すること:

- Apple Pencil と指の両方で線が引けるか、筆圧で太さが変わるか
- キャンバスを触ったときにページがスクロール／引っぱり更新されないか
- 日本語キーボードで解答入力ができるか（変換確定で誤送信しないか）
- 横向き・縦向きの両方でレイアウトが崩れないか

### デバッグ用パラメータ

`?debug=1` を付けると:

- 画面上部に S1〜S5 の移動ボタンが出る
- タイマーが 5 秒に短縮される
- 出題ポケモンが固定される（ピカチュウ → ヒトカゲ → フシギダネ …）
- 解答判定の自己テストがコンソールに出る

## ファイル構成

```
pokemon_quiz/
├── index.html          # 5画面すべてを含む本体
├── css/
│   ├── dex.css         # 図鑑筐体デザイン（共通パーツ）
│   └── screens.css     # 各画面固有のレイアウト
├── js/
│   ├── state.js        # 状態オブジェクト + sessionStorage 復帰
│   ├── dexdata.js      # 世代テーブル・出題プール計算・抽選・伏字処理
│   ├── dexsource.js    # 図鑑データの取得と組み立て（towakey + PokeAPI）
│   ├── judge.js        # 解答の正規化・あいまい一致判定
│   ├── canvas.js       # お絵描き（Pointer Events / undo / 消しゴム）
│   ├── sfx.js          # Web Audio 効果音（音声ファイルなし）
│   └── app.js          # 画面遷移・各画面のイベント配線（最後に読み込む）
├── robots.txt          # noindex
├── .nojekyll           # GitHub Pages 用
└── .gitignore          # 生成物・メモを除外
```

フレームワーク・ビルドツールは一切使っていません（バニラ HTML/CSS/JS）。
`js/*.js` はクラシックな `<script>` タグでこの順に読み込みます（`app.js` が最後）。

## 図鑑データの取り方

**このアプリは図鑑テキストを一切ホストしません。** リポジトリにも GitHub Pages にも
1文字も置かず、閲覧者のブラウザが配布元から直接取得します。理由は下の「方針」を参照。

取得元は2つで、**初回に 3 リクエスト・合計約1MB**（いずれも gzip 転送）だけです。
2回目以降は端末内のキャッシュから読むので通信しません。

| 取得元 | 何を取るか | 量 |
|---|---|---|
| [towakey/pokedex](https://github.com/towakey/pokedex)（jsDelivr 経由） | 赤・緑〜SV の日本語説明文、名前、分類 | 2ファイル・約590KB |
| [PokeAPI](https://pokeapi.co) の GraphQL | X・Y 以降の日本語説明文、タイプ、進化前 | 1リクエスト・約435KB |

この2つは互いの穴を埋め合います。PokeAPI に日本語説明文があるのは X・Y 以降の6ソフト・
No.1〜898 だけで、towakey は逆に ORAS と Let's Go がほぼ空です。重ねると全 1025 種が埋まります。

towakey の URL は**コミットを固定**してあるので、先方が更新しても壊れません。
更新に追従したいときは `js/dexsource.js` の `TOWAKEY_BASE` の SHA を差し替えてください。

### PokeAPI Fair Use への配慮

旧版は 1問1リクエストで合計 919 リクエストを発行し、当日に備えて「一括保存」を
3〜4分かけて回す必要がありました。GraphQL に変えたことで **1 リクエスト**で
全 1025 種ぶんがそろうため、一括保存の仕組みごと不要になりました。

GraphQL は POST なので Service Worker のキャッシュに載りません。
取得結果は `dexsource.js` が Cache Storage に自分で保存し、2回目以降は通信ゼロで起動します。

### 当日ネットが無くても遊ぶ

1. 自宅の Wi-Fi で公開 URL を Safari で開く（初回の読み込みで図鑑データがそろいます）
2. 共有ボタン →**「ホーム画面に追加」**

Service Worker がページ本体を、Cache Storage が図鑑データを iPad 内に保存するので、
**ネットがまったく無い会場でも最後まで遊べます**。正解発表のイラストだけは、
一度表示したものが Service Worker にキャッシュされる形なので、
心配なら事前に何ゲームか回しておいてください。

> Service Worker と Cache Storage は HTTPS でのみ動作します（GitHub Pages は HTTPS）。
> 開発用の `http://192.168.x.x:8000` では毎回取り直しになります。

### 方針：リポジトリに図鑑データを含めない

図鑑説明文の著作権は 任天堂・クリーチャーズ・ゲームフリーク・ポケモン にあります。
配布元が MIT ライセンスであっても、他社の著作物にライセンスを付与する権限は無いので、
**取得したデータをこのリポジトリにコミットしたり、GitHub Pages から配信したりしてはいけません。**
そうした時点で、複製と公衆送信を自分で行うことになります。

このアプリはあくまで「閲覧者のブラウザが配布元から直接取得する」構造を保っています。
`js/dexsource.js` の冒頭にも同じことを書いてあります。ここは変えないでください。
